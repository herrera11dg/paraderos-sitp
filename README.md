# Paraderos SITP - Bogotá

Aplicación web en PHP que consulta la API pública de Datos Abiertos Bogotá (SITP) y muestra la cantidad de paraderos por localidad.

## Cómo ejecutar

1. Instalar [XAMPP](https://www.apachefriends.org/) (incluye PHP)
2. Copiar el archivo `paraderos_sitp.php` en la carpeta `C:\xampp\htdocs\`
3. Iniciar Apache desde el panel de XAMPP
4. Abrir en el navegador: `http://localhost/paraderos_sitp.php`

## Funcionalidad

- Seleccionar una localidad de Bogotá
- Consultar la API de Datos Abiertos del SITP
- Mostrar la cantidad de paraderos zonales en la localidad seleccionada

## Tecnologías

- PHP 8.2
- API REST (OpenDataSoft - Datos Abiertos Bogotá)
- HTML/CSS
